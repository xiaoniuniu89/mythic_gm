# Random Events

**Random Events** inject unexpected narrative twists, complications, or opportunities into your adventure. They occur when triggered by Fate Questions (chart double-digit rolls or check doubles) or when an expected scene is **Interrupted**.

---

## ⚡ Step-by-Step Generation

To generate a Random Event, resolve the following three elements:

```
Context (Immediate situation) + Event Focus (What is it about?) + Event Meaning (Action & Subject)
```

1.  **Consider the Context:** What is currently happening in the story? The event must be interpreted to fit this context.
2.  **Determine Event Focus:** Roll **1d100** on the **Random Event Focus Table** to see which part of the adventure is affected.
3.  **Determine Event Meaning:** Roll two random words from the **Meaning Tables** (Action + Subject/Description) to get inspiration.
4.  **Interpret the Result:** Weave the Context, Focus, and Meaning words into a logical narrative development.

---

## 📊 Random Event Focus Table

Roll **1d100** to determine what the event is centered around:

| Roll (1d100) | Event Focus | Description |
|---|---|---|
| **1–5** | **Remote Event** | Something significant happens elsewhere, away from the characters. |
| **6–10** | **Ambiguous Event** | Vague, environmental, or mysterious event (not clearly good or bad). |
| **11–20** | **New NPC** | A brand new character enters the scene. |
| **21–40** | **NPC Action** | An existing NPC on your Characters List does something. *(Roll on List)* |
| **41–45** | **NPC Negative** | Something bad happens to an NPC on your Characters List. *(Roll on List)* |
| **46–50** | **NPC Positive** | Something good happens to an NPC on your Characters List. *(Roll on List)* |
| **51–55** | **Move Toward A Thread** | Events align to bring the characters closer to resolving a quest. *(Roll on List)* |
| **56–65** | **Move Away From A Thread** | A complication arises that stalls or pushes a quest further away. *(Roll on List)* |
| **66–70** | **Close A Thread** | A quest is resolved, completed, or rendered moot. *(Roll on List)* |
| **71–80** | **PC Negative** | Something unfortunate happens to the Player Character. |
| **81–85** | **PC Positive** | Something fortunate happens to the Player Character. |
| **86–100** | **Current Context** | The event relates directly to the immediate, local scene. |

## 🎲 Rolling on Lists (Threads & Characters)

When an event focus targets an NPC or Thread, you must select an element from the **Characters List** or **Threads List**. Mythic structures lists into sections of 10 items to act as dynamic random tables:

### Die Selection Method
1.  **Identify Active Sections:** Count how many blocks of 10 lines contain at least one written entry.
2.  **Choose the Section Die:**
    *   **1 active section (items 1–10):** Roll **1d10** directly.
    *   **2 active sections (items 1–20):** Roll a **1d4** (1–2 = Section 1, 3–4 = Section 2).
    *   **3 active sections (items 1–30):** Roll a **1d6** (1–2 = Section 1, 3–4 = Section 2, 5–6 = Section 3).
    *   **4 active sections (items 1–40):** Roll a **1d8** (1–2 = Sec 1, 3–4 = Sec 2, 5–6 = Sec 3, 7–8 = Sec 4).
    *   **5 active sections (items 1–50):** Roll a **1d10** (1–2 = Sec 1, 3–4 = Sec 2, 5–6 = Sec 3, 7–8 = Sec 4, 9–10 = Sec 5).
3.  **Roll the Target Line:** Roll a second **1d10** to select the specific item (1–10) within the determined section.
4.  **Empty Line Result:** If the rolled slot is empty, you may either **choose any active item** from the list manually, or roll again.

---

## 📖 Meaning Tables

Meaning tables generate **two-word prompts** (an **Action verb** and a **Subject noun/Description adjective**) to inspire the event details.

### Table Types
*   **Actions:** 100 verbs describing deeds, conflicts, and events (e.g. *Inspect, Assist, Debase*).
*   **Descriptions:** 100 adjectives/nouns describing moods, qualities, and themes (e.g. *Baleful, Peaceful, Ancient*).
*   **Elements:** Focus-specific lists of nouns categorized by location, character traits, objects, or themes.
